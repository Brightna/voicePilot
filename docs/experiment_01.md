# **실험 1. Whisper 모델 크기에 따른 한국어 음성 인식 성능 비교**

## **1. 연구 배경 및 목적**

VoicePilot은 사용자의 한국어 음성 명령을 인식하고, 이를 분석하여 프로그램 실행, 웹 검색, 파일 열기 등의 PC 제어 기능을 수행하는 시스템이다.

음성 인식 모델의 크기가 커질수록 일반적으로 높은 인식 정확도를 기대할 수 있지만, 연산량이 증가하여 응답 속도가 느려질 수 있다.

따라서 본 실험에서는 faster-whisper의 tiny, base, small 모델을 비교하여 CPU 환경에서 정확도와 처리 속도를 모두 고려한 음성 인식 모델을 탐색하고자 한다.

## **2. 연구 가설**

- 가설 1. 모델의 크기가 커질수록 문자 오류율(CER)이 감소할 것이다.
- 가설 2. 모델의 크기가 커질수록 음성 인식 처리 시간이 증가할 것이다.
- 가설 3. PC 제어 시스템에서는 정확도가 가장 높은 모델보다 정확도와 처리 속도의 균형을 갖춘 모델이 적합할 수 있다.

## **4. 예비 실험 및 문제 해결 과정**

이 부분은 이번 프로젝트에서 중요하게 다루면 좋겠어. 단순히 성공한 결과만 보여주는 것이 아니라 문제를 발견하고 해결한 과정이기 때문이야.

### **4-1. 문제 발견**

최초에는 3초 고정 녹음 방식으로 음성 데이터셋을 제작하였다. 그러나 모델별 인식 결과에서 다음과 같은 문제가 발생하였다.

- 문장 앞부분 및 뒷부분 손실
- 실제 발화와 무관한 문장 인식
- 긴 명령어의 불완전한 인식
- 발화 초반의 음성 품질 저하

녹음 파일을 직접 재생한 결과, 음성 인식 모델뿐만 아니라 입력 데이터 자체에도 문제가 있음을 확인하였다.

### **4-2. 문제 해결 과정**

1. **초기 3초 녹음 방식**

   문장 앞뒤 손실 및 낮은 녹음 품질 확인

2. **녹음 시간 8초로 연장**

   긴 문장을 녹음할 수 있는 시간 확보

3. **1초의 발화 준비 시간 추가**

   녹음 시작 이후 발화를 안내하도록 코드 수정

4. **마이크 입력 방식 변경**

   MME → Windows DirectSound

   첫 단어가 뭉개지는 현상은 여전히 발생함.

5. **Windows 오디오 향상 기능 비활성화**

   녹음 품질 개선 관찰

6. **전체 데이터셋 재녹음**

   동일한 개선 조건으로 데이터셋 재구성 및 모델 비교 실험 재실행

예비 실험 결과는 삭제하지 않고 별도로 보존하였다.

다만 오디오 향상 기능의 비활성화가 녹음 품질 개선에 영향을 주었을 가능성은 높지만, 반복적인 통제 실험을 수행하지 않았으므로 정확한 인과관계까지 확정할 수는 없다.

## **5. 성능 평가 지표**

### **5-1. 문자 오류율(CER)**

Character Error Rate는 정답 문자열과 인식 문자열 사이의 문자 단위 오류를 측정하는 지표이다.

\\[ CER=\frac{S+D+I}{N}\times100 \\]

여기서 S는 교체, D는 삭제, I는 삽입 횟수이며 N은 정답 문자열의 전체 문자 수이다.

예를 들어 다음과 같다.

정답

# **계산기켜줘**

인식 결과

# **계산이켜줘**

\\[ CER=\frac{1}{5}\times100=20\\% \\]

레벤슈타인 거리 알고리즘을 직접 구현하여 전체 데이터셋의 문자 오류율을 계산하였다.

### **5-2. 문장 완전 일치율(Exact Match)**

정답과 인식 결과가 완전히 일치하는 문장의 비율이다.

\\[ Exact\ Match=\frac{\text{일치 문장 수}}{\text{전체 평가 문장 수}}\times100 \\]

### **5-3. 처리 시간(Latency)**

음성 인식 요청부터 최종 텍스트 생성까지의 시간을 측정하였다.

평균값, 중앙값, 최대값을 계산하였으며 모델 로딩 시간, 음성 녹음 시간, 파일 읽기 시간은 제외하였다.

### **5-4. 평가 기준**

띄어쓰기와 문장부호 차이는 오류로 처리하지 않았다. 무음 데이터는 CER 및 완전 일치율에서 제외하여 별도로 평가하였으며, 처리 시간 통계에는 포함하였다.

## **7. 실험 결과 분석**

### **7-1. 모델 크기와 인식 정확도의 관계**

모델 크기가 증가함에 따라 문자 오류율은 감소하고 문장 완전 일치율은 증가하였다.

tiny → small

# **81.39% 감소**

문자 오류율의 상대적 감소율

16.23% → 3.02%

tiny → small

# **41.38%p 증가**

문장 완전 일치율

37.93% → 79.31%

따라서 본 데이터셋에서는 가설 1을 지지하는 결과가 나타났다.

### **7-2. 모델 크기와 처리 시간의 관계**

모델 크기가 증가함에 따라 평균 처리 시간도 증가하였다.

small 모델은 tiny 모델보다 약 4.16배, base 모델보다 약 2.68배의 처리 시간이 소요되었다.

따라서 가설 2 역시 본 실험 결과에 의해 지지되었다.

### **7-3. 정확도와 처리 속도의 상충 관계**

정확도와 처리 시간의 Trade-off 및 후속 연구 목표

PC 제어 시스템은 사용자의 명령에 신속하게 반응해야 한다. 따라서 정확도가 높더라도 처리 시간이 지나치게 길어지면 사용자 경험에 부정적인 영향을 줄 수 있다.

base 모델은 평균 1초 미만의 음성 인식 처리 시간을 기록하였으나, 완전 일치율은 58.62%로 정확도 개선이 필요하다.

이에 따라 base 모델을 후속 개선 연구의 주요 대상으로 선정한다. 단, 실제 사용자 경험이나 명령 실행 성공률을 측정하지 않았으므로 가설 3에 대한 최종 판단은 후속 실험으로 유보한다.

### **7-4. 특정 단어에 대한 공통 인식 오류**

| 정답          | tiny          | base          | small         |
| ------------- | ------------- | ------------- | ------------- |
| 크롬          | 그럼          | 그럼          | 그럼          |
| 인공지능 뉴스 | 인공지는 유쓰 | 인공지는 뉴스 | 인공지는 뉴스 |
| 메모장        | 외모 땀       | 외모장        | 메모짱        |
| 숭실대학교    | 송실대학교    | 송실대학교    | 숭실대학교    |
| 다운로드      | 다음 로드     | 다음 로드     | 다운로드      |

모델 크기를 증가시키더라도 특정 프로그램 이름이나 전문 용어에 대한 오류가 완전히 해결되지 않았다.

특히 PC 제어 시스템에서 프로그램 이름은 실행 대상을 결정하는 핵심 정보이므로, 단 한 글자의 오류도 명령 수행 실패로 이어질 수 있다.

따라서 일반적인 음성 인식 정확도뿐만 아니라 **PC 제어에 특화된 핵심 단어의 인식 정확도를 개선할 필요가 있다.**

### **7-5. 무음 및 짧은 발화의 처리 시간 문제**

| 발화    | tiny     | base     | small    |
| ------- | -------- | -------- | -------- |
| 무음    | 2.0358초 | 6.4285초 | 2.2237초 |
| 열어 줘 | 2.4158초 | 1.6709초 | 8.6722초 |

모든 모델이 무음 데이터를 빈 문자열로 정상 인식하였다. 그러나 일부 무음 및 짧은 발화에서 일반적인 명령보다 긴 처리 시간이 관찰되었다.

추후 VAD(Voice Activity Detection, 음성 활동 감지)를 적용하여 불필요한 무음 처리 및 응답 지연을 줄일 수 있는지 검증할 필요가 있다.

## **8. 실험의 한계**

- 단일 화자의 음성 데이터만 사용하였다.
- 전체 데이터셋이 30개로 규모가 작다.
- 각 모델의 음성 파일별 추론을 한 번씩만 수행하였다.
- CPU 및 메모리 사용량을 측정하지 않았다.
- 실제 명령어 분류 및 실행 성공률은 측정하지 않았다.
- 모든 녹음 파일의 품질을 개별적으로 검증하지는 않았다.
- 8초 고정 녹음 방식을 사용하였으므로 실제 사용자 응답 시간과 음성 인식 처리 시간에는 차이가 있다.

따라서 본 실험은 전체 사용자에 대한 일반적인 성능 평가보다는 VoicePilot의 초기 모델 선정과 개선 방향을 탐색하기 위한 기준 실험으로 활용한다.

## **9. 결론 및 후속 연구 방향**

본 실험에서는 faster-whisper의 tiny, base, small 모델을 대상으로 한국어 PC 제어 명령의 인식 성능을 비교하였다.

small 모델은 가장 높은 인식 정확도를 보였으나, base 모델보다 약 2.68배 긴 평균 처리 시간이 소요되었다.

또한 모델 크기를 증가시키더라도 프로그램 이름과 같은 특정 단어의 인식 오류는 여전히 발생하였다.
