# Experiment 05. 음성 활동 감지(VAD) 기초 연구

## 1. 연구 목적

고정 시간 녹음 방식의 한계를 분석하고, 음성 활동 감지를 통한 동적 녹음 방식의 적용 가능성을 조사한다.

## 2. 실험 환경

- 마이크: 인텔 스마트 사운드 기술 마이크 배열
- 입력 방식: Windows DirectSound
- 장치 번호: 5
- 샘플링 주파수: 16,000Hz
- 조건별 측정 시간: 5초
- 프레임 길이: 30ms
- 프레임당 샘플 수: 480개

## 3. RMS 측정 결과

| 조건        | 평균 RMS |   최댓값 |
| ----------- | -------: | -------: |
| 무음        | 0.000900 | 0.002008 |
| 작은 목소리 | 0.004935 | 0.020456 |
| 일반 목소리 | 0.009757 | 0.029663 |
| 큰 목소리   | 0.020020 | 0.135608 |
| 키보드      | 0.008304 | 0.027635 |
| 마우스      | 0.004428 | 0.013998 |

## 4. 임계값 비교 실험

8개의 RMS 임계값을 설정하고 조건별 임계값 이상 프레임의 비율을 비교하였다.

| 임계값 |  무음 | 일반 목소리 | 키보드 |
| -----: | ----: | ----------: | -----: |
|  0.002 | 0.60% |      65.06% | 98.19% |
|  0.003 | 0.00% |      62.05% | 92.77% |
|  0.005 | 0.00% |      58.43% | 75.30% |
|  0.007 | 0.00% |      51.20% | 53.61% |
|  0.010 | 0.00% |      43.98% | 27.71% |
|  0.015 | 0.00% |      33.13% |  8.43% |
|  0.020 | 0.00% |      16.27% |  2.41% |
|  0.030 | 0.00% |       0.00% |  0.00% |

해당 비율은 실제 음성 감지 정확도가 아닌 임계값 이상 프레임의 비율이다.

## 5. 연구 결과 및 한계

- 임계값 0.003 이상에서 측정된 무음 프레임이 모두 차단되었다.
- 키보드 소음의 평균 RMS가 작은 목소리보다 높게 나타났다.
- 고정 RMS 임계값만으로 사람의 음성과 주변 소음을 구분하기 어렵다.
- 마이크 종류, 입력 볼륨, 사용자와 마이크 사이의 거리 및 주변 환경에 따라 적절한 임계값이 달라질 수 있다.
- 단일 환경에서 조건별 1회 측정한 탐색 실험이므로 결과를 일반화하기 어렵다.

## 6. 개발 방향 결정

고정 RMS 기반 VAD의 환경 의존성을 고려하여 실제 시스템 적용을 보류하였다.

후속 기능 개발을 우선 진행하기 위해 기존 3초 고정 녹음 방식을 5초 고정 녹음 방식으로 변경하였다.

변경 이후 기본 음성 인식 기능이 정상적으로 동작함을 확인하였다. 다만 5초 녹음 방식의 최적성이나 정확도 개선 효과를 정량적으로 검증하지는 않았다.
